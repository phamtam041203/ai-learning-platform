 RUN COMMANDS — AI Learning Platform

> Máy: Windows, PowerShell  
> Docker: `C:\Program Files\Docker\Docker\resources\bin\docker.exe`  
> Thư mục gốc: `d:\KLTN\ai-learning-platform`

---

 0. Chuẩn bị một lần duy nhất

```powershell
 Vào thư mục gốc
cd d:\KLTN\ai-learning-platform

 Thêm Docker vào PATH (nếu lệnh docker chưa nhận)
$env:PATH = "C:\Program Files\Docker\Docker\resources\bin;" + $env:PATH

 Kiểm tra Docker hoạt động
docker version
docker compose version
```

 1. DEV — phát triển local (hot-reload)

| Service    | URL                               |
|------------|-----------------------------------|
| Frontend   | http://localhost:5173             |
| Backend    | http://localhost:8000             |
| API docs   | http://localhost:8000/docs        |

```powershell
cd d:\KLTN\ai-learning-platform

 Khởi động (build lần đầu)
docker compose --env-file .env.docker up --build

 Khởi động nhanh (không build lại)
docker compose --env-file .env.docker up

 Chạy ngầm (background)
docker compose --env-file .env.docker up -d

 Dừng
docker compose --env-file .env.docker down

 Dừng và xóa volume (reset database)
docker compose --env-file .env.docker down -v
```

| Service    | URL                               |
|------------|-----------------------------------|

| Web public | http://1.54.153.94                |

> File env dùng: `.env.vps`  
> Chỉ port 80 được expose ra ngoài.


 4. CLOUDFLARE QUICK TUNNEL — URL public tạm thời

> URL đổi mỗi lần restart. Không cần port forwarding, không cần domain.

```powershell
cd d:\KLTN\ai-learning-platform

 Chạy tunnel (cần VPS stack đang chạy ở port 80 trước)
scripts\start-cloudflare-tunnel.bat

 Hoặc gõ tay
tools\cloudflared\cloudflared.exe tunnel --url http://localhost:80
```

Quy trình:
1. Chạy VPS stack trước (`scripts\deploy.bat`)
2. Chạy tunnel (`scripts\start-cloudflare-tunnel.bat`)
3. Copy URL `https://xxxx.trycloudflare.com` hiển thị trong terminal
4. Chia sẻ URL đó cho người dùng

 10. Troubleshoot nhanh

```powershell
 Rebuild hoàn toàn (xóa cache)
docker compose --env-file .env.docker build --no-cache

 Xem tài nguyên Docker
docker system df

 Dọn dẹp image/container không dùng
docker system prune

 Dọn dẹp kể cả volume (CẢNH BÁO: mất data DB)
docker system prune -a --volumes

 Restart 1 service
docker compose --env-file .env.docker restart backend

 Vào shell trong container backend
docker compose --env-file .env.docker exec backend bash

 Chạy migration DB
docker compose --env-file .env.docker exec backend alembic upgrade head
```
